# 🏢 Apartman Yönetim Sistemi

Bu mobil uygulama, apartman yöneticileri ve sakinleri için geliştirilen bir **Apartman Yönetim Sistemi**dir. Fatura takibi, duyuru paylaşımı, aidat ödemeleri ve daha fazlası kolaylıkla yönetilebilir.

> ⚠️ Bu proje **hala geliştirilmektedir**. Yeni özellikler ve arayüz iyileştirmeleri düzenli olarak eklenmektedir.

---

## 🚀 Teknolojiler

- ⚛️ **React Native** (JavaScript)
- 🔥 **Firebase**
  - Authentication
  - Firestore
  - Storage
  - Realtime Database
- 📱 Mobil Uyumlu Tasarım
